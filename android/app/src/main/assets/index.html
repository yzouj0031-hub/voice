快速填入

👆 点一个就自动填好“接口类型/地址/模型”，你只需在下面粘贴自己的 API 密钥（注意：API 密钥不等于 ChatGPT/Gemini 会员账号，要到对应的开发者平台单独获取）。
• Gemini·免费：去 aistudio.google.com/apikey 免费领 Key，填好后点“↧ 拉取模型”可选最新可用模型。
• 智谱·免费：去 open.bigmodel.cn 注册后在控制台复制 Key，glm-4-flash 免费。
• OpenAI 需在 platform.openai.com 开通并绑卡（ChatGPT 会员不含 API）。

☁️ 云端识别：App 自己录音，直接把声音发给你的 AI 接口"听"，完全绕开手机系统的语音识别——自检里"语音识别服务 ✗"的手机（如部分 vivo/无谷歌服务机型）请选这个。用法：点麦克风开始录音，再点一下发送。要求所用模型能听音频（Gemini 系列可以，推荐 gemini-2.5-flash）。

语音唤醒（喊一声就出现）
开启后即使退出 App，喊唤醒词也会自动弹出并开始聊天

⚠️ 语音唤醒用的是App 自带的离线引擎，不依赖手机系统的语音识别（系统识别坏了也能用）。首次开启会下载一次约 42MB 的中文唤醒模型（需联网，之后完全离线）。持续监听会更耗电。首次开启还会引导你授予“显示在其他应用上层”权限（否则喊了只弹通知、不会跳出来）。退出 App 后喊唤醒词即可唤起。

👆 唤醒喊了没反应时点这个：会当场用离线引擎听你说话，实时显示它听到了什么。对手机说“你好助手”——若显示的文字接近、并出现“✅ 听到唤醒词”，说明识别没问题（那问题在后台弹窗权限）；若一直识别不出或是乱码，那就是识别没听清，我来调。

常见填法：DeepSeek → 地址 https://api.deepseek.com/v1，模型 deepseek-chat；Kimi → https://api.moonshot.cn/v1，moonshot-v1-8k；Claude → 接口类型选 Anthropic，地址 https://api.anthropic.com，模型 claude-haiku-4-5。

💡 直接说“给妈妈打电话”“订个早上七点的闹钟”“定时十分钟”“打开微信”“导航去火车站”，我就会帮你做。首次用到打电话/找联系人时，系统会请求相应权限，允许即可（发短信、加日历会先打开对应应用让你确认，更安全）。
